# Security

Do not publish security reports publicly. Use GitHub's private vulnerability reporting for this repository after it is enabled. Until then, contact the maintainer through the repository profile without sending secrets or private note contents.

Report suspected vulnerabilities directly to the product owner with reproduction steps and the affected version. Never include real API keys, access tokens, or private note contents in a report.

Integration credentials are stored in macOS Keychain. Notes remain in the user-selected local or iCloud Drive vault. The optional AI gateway uses a separate activation token and does not store note text.
